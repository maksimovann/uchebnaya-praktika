# Разработка интерфейса

В `web` находятся HTML, CSS и JavaScript интерфейса CRM. В `resources` находятся уникальные логотип и иконка приложения. Заголовок страницы: «CRM: Список партнеров и скидок».

Интерфейс выполнен в виде списка карточек по предоставленному образцу. Запускаемая версия, связанная с базой данных, находится в четвертом задании.
