# Навигация между окнами

В `web/index.html` созданы экраны `MainWindow` и `PartnerEditWindow`. Код переключения находится в `web/app.js`.

- «Добавить партнера» открывает пустую карточку.
- Нажатие на карточку открывает режим редактирования.
- «Назад» и «Отмена» возвращают в реестр без перезагрузки страницы.
- Состояние поиска и загруженного списка сохраняется.
- Заголовки: `CRM: Реестр партнеров`, `CRM: Карточка партнера [Добавление]` и `CRM: Карточка партнера [Редактирование]`.

Запускаемая версия находится в четвертом задании этого этапа.
