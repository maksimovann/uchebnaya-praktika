# Интеграция формы с БД

В этой директории находится запускаемая версия с CRUD API.

- `POST /api/partners` создает партнера.
- `GET /api/partners/{id}` загружает карточку.
- `PUT /api/partners/{id}` обновляет существующую запись.
- После сохранения UI повторно получает список и показывает актуальные данные.
- Внешние ключи отгрузок не изменяются, идентификатор партнера при редактировании сохраняется.
- SQLite использует `PRAGMA foreign_keys = ON`; PostgreSQL работает с существующими ограничениями схемы.

Команды запуска и проверки приведены в четвертом задании. Тесты CRUD находятся в `tests`.
