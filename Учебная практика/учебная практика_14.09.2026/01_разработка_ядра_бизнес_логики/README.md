# Разработка ядра бизнес-логики

В `discount.py` реализована изолированная функция `calculate_partner_discount(total_quantity)`. Тесты проверяют значения `9999`, `10000`, `49999`, `50000`, `300000`, дополнительные границы и ошибочный отрицательный объем.

Запуск тестов из этой директории:

```powershell
python -m unittest discover -s tests -v
```

Измеренное покрытие строк `discount.py` встроенным модулем Python `trace` составляет 100%.
