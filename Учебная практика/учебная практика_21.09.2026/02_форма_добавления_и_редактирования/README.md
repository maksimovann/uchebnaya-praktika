# Форма добавления и редактирования партнера

Форма находится в `web/index.html`, оформление — в `web/app.css`.

Реализованы наименование, выпадающий список типа партнера, целочисленный рейтинг, адрес, ФИО директора, ИНН, телефон и email. Поля телефона и email содержат подсказки ожидаемого формата. В JavaScript оставлен один краткий комментарий у неочевидной логики сохранения состояния между экранами.

Запускаемая версия находится в четвертом задании этого этапа.
